# 数据流与边界

本文描述当前仓库源码的行为，不代替网易云、阿里云或 Apple 各自的服务政策。

## 本机处理

- **听歌与偏好**：本地数据库保存模型参数、有限决策快照、播放证据和操作事件；搜索 / 歌单点播也可积累后续反馈。
- **健康**：用户授权后读取健康记录并在本机形成带新鲜度、缺失状态及个人基线的摘要。不会向歌曲或照片云端模型发送健康数据，不修改 Apple 健康数据。学习数据中可能包含衍生情境特征；「不保留健康原始档案」不等于学习库里完全没有健康衍生信息。
- **位置**：主动定位与命名地点在本机匹配，保存精确地点坐标；不会把精确坐标作为云端请求字段。语义地点及观察时间可以随主动照片分析发送。
- **凭据**：网易云会话和阿里 API Key 使用设备 Keychain。网易云请求会使用网易云会话；阿里请求会使用阿里 Key，两者不交叉发送。
- **BPM**：取得有权限播放的音频资源后在设备上分析，临时音频受下载上限约束，不上传到云端模型。

## 主动照片分析

选择照片并发起分析后，App 会预处理图片、去除位置等元数据，并向阿里云发送：

1. 当前照片，以及当前保留策略范围内的近期图片。
2. 各图的拍摄时间（如能读取）、选择时间和用于理解的当地时间。
3. 有限的近期场景摘要、你填写的说明 / 感受，以及可选语义地点与时间。

图片中可见的人脸、门牌、文字等仍可能透露信息；去除 EXIF 不会自动遮挡画面。请只选择愿意发送给服务商的内容。

默认策略为近期 **最多 5 张 / 24 小时**；另有近 2 小时 / 3 张和只保留摘要策略。图片副本在受 iOS 文件保护、排除备份的缓存目录中。有效期按选择时间计算，在 App 可运行的定时清理与后续读取时清除过期内容；系统暂停 App 时，不保证到点立即执行物理删除。

「只保留摘要」仍会为本次分析发送当前照片和近期摘要，不能解读成完全不上传图片。用户可在界面清除场景记忆；这不等于删除服务商侧已有请求记录。

## 歌曲文本分析

启用后发送歌名、艺人与实际取得的歌词摘要，形成可缓存的歌曲内容档案。不会发送健康原始记录、完整听歌历史或网易云凭据。文本分析结果不是对歌曲音频的直接测量。

## 网络与费用

当前原生 App 不需要项目自建后端。音乐、歌词和封面来自音乐服务，云端分析使用阿里百炼北京地域接口。服务商可见请求所必需的网络信息。

本机在调用前持久化预留费用，拿到可核验的 usage 后结算；失败且费用未知时保留预留，不自动重复付费重试。照片与歌曲分析共用按上海时区计算的每日 ¥1、累计 ¥8 预算。移除或替换 Key 不重置已有预算账本。

预算仅约束当前 App 的记账调用，不是阿里云账户级消费上限，也不包含其他应用消费。代码中的模型与价格是假设快照，服务商变化后需要更新；应自行配置服务商侧可用的消费管理措施。

## 公开仓库的范围

仓库包含源码、合成测试及展示素材，不含个人数据库、设备日志、私人照片、Key、Cookie、证书或已签名安装包。提交 issue / PR 前也请检查这些信息；`.gitignore` 只是辅助，不会自动清理已经提交的敏感文件。
