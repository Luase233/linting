## 评分：先解释单位，再解释大小

当前四个参与排序的在线目标是 `continuation`（实际持续收听）、`fit`（明确主观合适）、`affinity`（长期偏好）、`replay`（实际回听）。输入包括歌曲 / 艺人、召回来源、时间及可用情境，以及情境与音乐属性的交互。缺失特征不会冒充已知数值。

每个头的 sigmoid 输出位于 0–1，但未经校准，不能解读成真实成功率；它们也不互斥。当前评分是：

```text
S = P + 1.4(C − 0.5) + 2.4(F − 0.5) + 2(A − 0.5) + 0.8(R − 0.5)
```

`P` 是明确喜欢、常听艺人、近期重复控制及明确意图等直接贡献。新颖性没有额外加分；同属某个召回来源也不构成重复曲风证据，重复控制使用歌曲和实际艺人。

`fit` 只训练有界哈希中的曲目×情境特征，不更新艺人 / 来源共享权重。哈希有 4096 个桶，存在碰撞可能，不能声称绝对隔离。其他模型仍可泛化。旧版 acceptance / rejection 权重保留但不参与新排序；新的 C / F 头从空权重积累，避免目标偷换。旧快照按旧公式对账。

## 召回与选择

候选通道包括收藏 / 熟悉曲、多个常听艺人、近期会话邻近、意图相关检索及有限通用发现。收藏 ID 缺少名称时分批补元数据并缓存。通道配额让情境与发现通道不被大量收藏完全挤掉；地点或体征不会被机械映射成某个曲风。

主要选择池为距最高分不超过 0.75 的前 3 首；探索池为主要池之外、距最高分不超过 0.9、具有兴趣关联且有效目标记录不足 3 项的最多 3 首。两池互斥，均以温度 0.25 的 softmax 分配各自预算。

探索预算为 `0.1 × discovery / (1 + recentSkipRun)`，其中 discovery 归一化到 0–1；连续早跳达到 3 次或没有合格探索候选时归零。最近会话中明确不合适的歌曲不能直接通过探索回来；后续明确合适可解除。明确不喜欢的歌曲被排除。

日志分别记录最终概率、主要池概率、探索概率与角色；以最终概率进行真实抽样。新歌可能直接进入主要池，因此「新歌比例」和「探索比例」不是同一指标。以上配额与阈值均未经过大规模最优性验证。

## 版本、结果与可追溯性

候选快照保存名称、艺人、召回通道、预测前特征、模型 / 标签版本、该曲有效目标记录数和真实策略概率。手动点播没有已知 propensity；播放失败重选通过父决策 ID 关联。

完整资源在有效观测内实际输出并唯一覆盖至少 60 秒，持续收听标签为 1；不足窗口的明确用户早跳为 0。未知长度、试听、故障、系统中断、未观察结果及诊断播放不转成负样本。诊断记录仍可审计，但不更新偏好与会话计数。

## 反馈应与动作含义一致

播放证据记录真实输出时长和唯一覆盖，拖动跳过的位置不会虚增听歌时长。自动结束、预览结束、错误结束、手动切换分别处理；单次点按重听不能代替实际重听证据。

「此刻合适 / 不合适」只更新独立的曲目×情境目标，避免变成对艺人或歌曲的全局厌恶。撤销喜欢向中性更新，并不声称精确撤销所有历史训练。

SQLite 使用后台串行写入和增量保存，保留模型状态、有限决策与播放事件。预取候选和播放地址减少切歌等待，但网络、服务响应及媒体解码仍可能造成延迟。

## BPM：音频证据与覆盖一起保存

实际音频由有上限的下载管道取得，压缩资源上限为 16,000,000 字节。较长歌曲从前、中、后分散抽取最多三个 24 秒窗口；短资源按实际长度调整。各段估计后做一致性与半拍 / 双拍歧义检查。

系统记录片段位置、结果与置信度。预览、未知完整性、片段冲突、下载受限等状态与可信结果区分，不能把某个片段的结果包装成整首歌的已确认 BPM。歌词与标题分析不参与音频节拍测量。

## 照片、意图与位置

云端请求包含当前与近期选择的图片、各自时间、有限场景摘要，以及可选用户自述 / 语义地点。拍摄时间与选择时间分开记录，缺失 EXIF 时不编造拍摄时刻。图片先去除元数据，精确坐标不发送给模型。

意图属于可被纠正的假设，用户自述优先；照片不能确认内在心理状态。云端结果经过结构与可信度检查，不可信字段被舍弃。分析失败不会自动循环付费重试。

新地点存储与距离匹配使用 WGS-84，大陆高德底图显示时才做显式转换；转换仅用于地图展示和选点回读，避免整体偏移或重复转换。

## 情境时效与对照

图片场景及未确认意图在 30 分钟内衰减，确认 / 自述意图和主动填写的感受最长参考 2 小时。定位质量乘以新鲜度；一般地点 15 分钟、移动线索 5 分钟失效。可靠的位置变化会使旧图片推断失效，但不覆盖明确自述。这些时限与图片缓存 24 小时的保留期无关。

同一轮候选分别移除图片、地点与健康线索，重建完整特征（包括哈希交互），计算逐曲分数差、排名差和策略分布的总变差。图片请求已使用地点时标记共享来源，避免再次加入相同地点特征；不能把这些对照相加当作独立收益。

`scripts/evaluate-recommendations.py` 只读取本地导出的 SQLite，按新标签版本关联选择前预测和后续结果，报告较晚时间片的 Brier / log loss、可靠性分箱、样本量及描述性区间。模型在在线更新，因此这是按时间顺序的预测审计，不是冻结模型实验。主观评价存在自选偏差，重复播放存在相关性；当前没有启用经过验证的概率校准器。真实增益仍需完整会话对照和长期试用。
